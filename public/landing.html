FAQ & trust

Before you paste in a key.

What is this?

Mealwise turns a few lines about what you like to eat into a full week of meals. Paste in your own Anthropic API key, describe your week, and get a plan back — no account, no sign-up, nothing saved on our end.

Do I need an API key?

Yes — Mealwise doesn’t come with its own AI access, so you’ll need your own Anthropic API key to generate a plan. If you don’t have one yet, you can get one at console.anthropic.com (opens in a new tab).

Is my API key stored anywhere?

Your key is used only to generate your plan — Mealwise’s server relays each request to Anthropic in real time, and never logs or stores it. (Your browser may remember it locally so you don’t have to re-paste it next time.)

Is this free to use?

Mealwise itself is free — there’s no fee to use the tool. You do pay Anthropic directly for your own API usage, based on their current pricing.

Which AI model powers this?

Mealwise is powered by Claude, Anthropic’s AI model — the same one your API key gives you access to.

What if my API key runs out of credits?

Generation will fail with an error until you add more. You can top up your credits anytime at console.anthropic.com (opens in a new tab) and try again. (If you see an error right away instead, double-check your key starts with sk-.)
